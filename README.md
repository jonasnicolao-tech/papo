# Papo

Mensageiro de janela azul. A lista, a conversa, a cutucada, o arquivo, a voz, a ligação e o jogo ficam neste aparelho.

Não é o cliente antigo de outra marca. O nome, o logotipo e a borboleta não são usados.

## O que tem

- Entrar com e-mail (a senha não é guardada), lembrar e entrar sozinho
- Status, foto, mensagem pessoal e o que você está ouvindo
- Grupos, busca, adicionar, bloquear e conversa em grupo
- Abas, negrito, itálico, sublinhado, cor, tamanho e fonte
- Emoticons, cutucada, piscadela, arquivo, clipe de voz, ligação e câmera
- Jogo da velha e pedra, papel ou tesoura
- Avisos, som, histórico e bandeja

## Rodar

```bash
npm install
npm run dev
```

Abre no navegador o endereço que o comando mostrar.
